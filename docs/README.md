# ittracks user guide

To install or run your own server, see the [main README](../README.md#self-host).

## Words the app uses

| Term | Meaning |
| --- | --- |
| Habit | What you track: **Build** (something to do) or **Break** (something to stop) |
| Variant | A version of a habit, like Push day A and Pull day B. Most habits have one |
| Slot | A place in a Variant, holding a fixed Task or picking one by tags (an auto-filled slot) |
| Task | A reusable thing you do, kept in your Library: an exercise, "new words", "read" |
| Metric (field) | A value a Task logs: number, count, duration, checkbox, choice or text |
| Occurrence | One habit on one date: due, done, skipped or missed |
| Entry | One row of logged values, such as one set |
| Slip | A logged lapse of a break habit |
| Level | **Minimum** (the two-minute version), **Target** and **Stretch** |
| Group | A habit whose days come from the habits inside it |
| Routine | A habit with its own days and habits inside it that follow it |
| Area | A life area (Fitness, Learning…) for grouping and filtering habits and Tasks |
| Day start | When your day rolls over (default 04:00). Logs before it count for the day before |
| Part of the day | A named time range such as Morning 05:00–11:00, set in **Settings → Parts of the day** |
