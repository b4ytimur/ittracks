# Notes and journal

## Notes

Habits, Tasks, logs and slips can each have notes. Every note is plain Markdown, written in a box with **Write** and **Preview** tabs and buttons for bold, lists and links.

- A habit's **Notes**: why it matters, the plan, links.
- A Task's notes show as **How to** on its log screen.
- A log's note sits at the bottom of the log screen.

For safety, raw HTML is off, only web, mail and in-app links are kept, and images show as links. Notes from a shared template can't run code or load tracking pixels.

Notes and journal entries are private: they never go into templates, and a key needs **Notes** access to read them (see [Integrations](integrations.md#keys)). A habit's note and its Tasks' How-to notes go into a template only when you tick them on the share page.

## Writing fields

A Task's **Text** field can hold a journal entry or a reflection. In the Task editor:

- **Several lines (Markdown), for a journal entry or a reflection** turns it into a writing box.
- **Starter text** fills each new log, like headings to write under (`## Wins`, `## Lessons`).
- **Prompts, one per line**: one shows each day and is saved with your answer. **Which prompt each day**: **In order, one a day**, or **Random, the same all day**.

A **Choice** field can give each option a number (**Give each option a number, so Stats can chart it**), so a mood of Great / OK / Bad becomes 5 / 3 / 1 and Stats can average it.

## Journal

A journal is a normal habit with a writing field. Set one up from **Habits → New habit → Start a daily journal**, the **Journal** page, or the Gallery ("Journaling", "Gratitude"). The setup offers:

- **Add a Journal habit**: a few lines each evening with a daily prompt, and a mood you can chart in Stats.
- **Add a day note to Today**: one free note per day, no streak.

The journal is **History** with **Notes only** on: everything you wrote, by day, newest first. **Search** for words in any entry, filter by **Habit** and **Mood**, and see **On this day**: what you wrote a week, a month and a year ago. **Edit** opens an entry's log.

## The day note

**Settings → Journal → A day note on Today** adds one free note per day to Today and the day page. It has no streak.

## Export to Obsidian

**Settings → Journal → Download the journal** (or **History → ⋯ → Export the journal**) downloads your journal as Markdown, one file per day, ready to drop into an Obsidian vault.

## Switching the journal off

**Settings → Features → Journal** hides the journal and the day note. Nothing is deleted, and switching it back on brings everything back.
